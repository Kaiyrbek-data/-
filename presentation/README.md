# Презентация для защиты

Defense_slides.pdf содержит 17 проверенных слайдов в формате 16:9. PDF собрана из точных изображений слайдов: текст в ней не редактируется как текстовый объект.

Редактируемая оригинальная презентация сохранена в Spaces в текущем аккаунте. Из её viewer можно скачать PowerPoint. Идентификатор Page: page_cd50f8abc8fc819189a448116cda7b23.

Файлы slides/slide-01.png ... slide-17.png — исходные изображения для детерминированной пересборки PDF через `python scripts/slides_pdf_from_renders.py` (нужен reportlab). Они не заменяют редактируемую оригинальную презентацию.

Перед сдачей требуется подтвердить фактический вклад каждого участника и обновить соответствующий слайд вместе с отчётом.
